# 🐍 Python с нуля — Telegram Mini App

Тренажёр по Python внутри Telegram. Он построен на гарвардском курсе **CS50's Introduction to Programming with Python (CS50P)**.

- **10 разделов, 43 темы, 84 задачи.** В каждой теме:
  - короткий конспект на русском;
  - главы лекции CS50P с таймкодами и видео прямо в приложении;
  - практика после теории.
- **Настоящий Python в браузере.** Код проверяется [Pyodide](https://pyodide.org) (CPython 3.14, собранный в WebAssembly) прямо на устройстве, сервер не нужен.
- **Проверка по тестам:**
  - программы: ввод → вывод, аргументы командной строки, файлы;
  - функции и классы;
  - задачи на написание тестов: они прогоняются настоящим `pytest` на правильной и на «сломанных» реализациях.
- **Понятные отчёты об ошибках.** Трейсбек показывает строку ученика, а подсказки объясняют частые ошибки.
- **Прогресс в облаке Telegram (CloudStorage).** Он общий для телефона и компьютера.

## Как это устроено

| Файл | Что делает |
|---|---|
| `index.html`, `style.css` | Каркас и оформление под тему Telegram (светлая и тёмная) |
| `app.js` | Экраны, навигация, редактор кода (CodeMirror), прогресс, кнопки Telegram |
| `worker.js` | Отдельный поток с Python (Pyodide): в нём выполняется и проверяется код |
| `course.json` | Курс: разделы, темы, тексты, задачи (собирается скриптом из исходников курса) |
| `py_bundle.json` | Python-часть проверки: `checker.py`, `runner.py`, `webrunner.py`, `webcheck.py` и задачи с тестами |

Код ученика выполняется в том же интерпретаторе, но изолированно:
- у каждого теста своя временная папка;
- после теста восстанавливаются потоки ввода-вывода и `sys.argv`, а модули выгружаются;
- время ограничено через `sys.settrace`;
- если код «повесит» Python внутри встроенной функции, поток перезапускается.

Скрытая страница `#/selftest` прогоняет все эталонные решения через браузерный Python.
